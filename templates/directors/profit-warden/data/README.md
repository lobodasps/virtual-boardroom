# Data for the Lean Operator / Profit Warden

Put files here that this director should bring to every session. They are private to this director.
Put files in `shared/` to make them visible to the whole board.

`/virtual-boardroom:director attach` copies files in, converts Word, Excel and PDF to text, assigns each one a
citation tag such as `[PW1]`, and records it in `index.json`. Pinned items are read in full every session.
